# Abacus

Abacus is a calculator for mathematical expressions with a separate calculator memory.

## Language

**Expression**:
Mathematical text supplied for calculation. Typing and pressing calculator buttons are two ways of composing the same expression.
_Avoid_: Input, when referring to the mathematical text rather than the act of entering it.

**Result**:
The value obtained by successfully evaluating an expression.

**Calculator memory**:
A stored value kept separately from the current expression for reuse in calculations.
