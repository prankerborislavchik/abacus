# Тесты

`calculator/expression_editing_test.dart` проверяет редактирование через реальные события мыши и клавиатуры Flutter: последовательную вставку, замену выделения функцией и повторное удаление. Сценарии запускаются с настройками macOS, Windows и Linux; это widget-тесты, а не нативные запуски этих ОС.

`calculator/expression_alphabet_test.dart` проверяет алфавит, атомарный отказ вставки через сочетания клавиш, контекстное меню и accessibility, сохранение выделения и прежней диагностики. Буфер обмена подменяется только в тестах.

Запуск: `fvm flutter test`. Формат файлов и требования описаны в [README](../README.md#проверки).

`expression_parser_test.dart` проверяет публичный AST, приоритеты, допустимые и ошибочные строки, а также совместимость с существующим вычислителем. `expression_validation_test.dart` проверяет общий путь `=`/Enter, передачу AST, сохранение выражения и скрытие ошибки после редактирования. Это дополнение к нативной проверке, а не её замена.

`calculator/validation_memory_test.dart` проверяет совместную работу валидации и памяти: сброс устаревшего результата до разбора, сохранение памяти при ошибке, публикацию нового результата через callback и разбор научной записи после MR. Вычислитель подключается только тестовым callback; интеграция приложения остаётся в #5.
