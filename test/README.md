# Unit-тесты

Тестовая зависимость `flutter_test` подготовлена в `pubspec.yaml`. На этапе графического каркаса тестовых файлов нет.

Будущие тесты логики размещаются в `test/calculator/*_test.dart` и запускаются командой `fvm flutter test`.

Обязательные сценарии определяются в issue; [правила приёмки](../docs/contributing.md#unit-тесты-и-приёмка) описывают требования к тестам и включение их запуска в CI.
